# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux Toolkit shopping-cart application for an online houseplant store. The project was created for the IBM **Developing Front-End Apps with React** final project.

## Project features

- Landing page with the Paradise Nursery company name, background image, company information, and a **Get Started** button
- Product catalog organized into three categories with six unique houseplants in each category
- Product thumbnails, descriptions, and prices
- Redux-powered shopping cart
- Add-to-cart buttons that disable after a plant is added
- Dynamic cart icon count based on total quantity
- Shared navigation links for Home, Plants, and Cart
- Cart quantity controls, per-item totals, full-cart total, deletion, checkout message, and continue-shopping navigation

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```
